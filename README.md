## Parte 1 – Conceitos de Internet (2,0 pontos)

**1. Explique a diferença entre: Internet e Web; HTTP e HTTPS; Front-end e Back-end.**
**- Internet e Web:** A Internet é a rede que conecta computadores e dispositivos no mundo todo. A Web é um serviço dentro da Internet usado para acessar sites e páginas.

**- HTTP e HTTPS:** HTTP é o protocolo usado para a comunicação entre navegador e servidor. HTTPS é a versão mais segura, pois protege os dados usando criptografia.

**- Front-end e Back-end:** Front-end é a parte visual de um site ou sistema, aquilo que o usuário vê e interage. Back-end é a parte por trás do sistema, responsável pelo processamento e armazenamento dos dados.

**2. Descreva o que acontece quando digitamos uma URL até a página ser exibida.**
O navegador consulta o DNS para encontrar o servidor do site, faz uma conexão e envia uma solicitação. O servidor responde enviando os arquivos da página, e o navegador monta e exibe o site.

**3. Qual a função do DNS?**
Transforma o nome de um site (como google.com) em um endereço IP, permitindo que o navegador encontre o servidor correto.

**4. Cite três métodos HTTP e explique quando utilizá-los.**
**- GET:** usado para buscar informações.
**- POST:** usado para enviar dados para o servidor.
**- PUT:** usado para atualizar informações existentes.
